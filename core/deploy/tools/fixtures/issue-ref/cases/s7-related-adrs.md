Sensitivity fixture S-7 — the near-miss twin of the recognized-heading set.

A cross-ADR-link section is deliberately NOT a designated reference block: the
authoring guide forbids a bare reference there outright, so recognizing it would
move the placement cut point above the very section where the reference is
prohibited. The heading below is the closest miss in the whole heading family —
it opens with a recognized word and then keeps going, which is exactly what the
end-of-line anchor exists to reject.
