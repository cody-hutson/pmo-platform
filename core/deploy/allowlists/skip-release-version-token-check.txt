# Allowlist for the unresolved release-version token gate (deploy.sh Check 63 +
# core/deploy/tools/check-release-version-tokens.py).
# One path per line; matched as a whole-line exact path; `#` = comment.
#
# These files legitimately CONTAIN the claim token because they DEFINE, DOCUMENT,
# RESOLVE, or HISTORICALLY RECORD it — in each the token is the SUBJECT of the
# text, not an instance awaiting substitution. No lexical property separates the
# two (a token quoted in a protocol doc and a token in a template field are the
# same string), so the split is adjudicated per path and recorded here. A carrier
# NOT on this list is a finding — new carriers fail closed by design.
#
# The pre-claim release plan is NOT listed: it is excluded by the predicate
# itself, because carrying an unresolved token is what makes it pre-claim
# (ADR-092 claim-state oracle, read as such by Check 59). An exclusion that is a
# property of the identity model does not belong in an exceptions list.
