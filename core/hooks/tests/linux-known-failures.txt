# linux-known-failures.txt — the hook-harness failures the Linux job tolerates for now.
#
# Read by check-known-failures.py, which is the Linux hook-harness job's verdict: the job is
# green only when every failure the run shows has a row here, and red on any other failure,
# on a suite that ran without a summary line, or on a missing AGGREGATE line.
#
# This list is a stopgap, not an exemption. Every row is a defect that is fixed under its own
# work item, and the row is removed in the change that fixes it. The Linux job becomes a
# required check once this file holds no rows.
#
# Format: suite|arm|class|reason
#   suite   the suite file name
#   arm     a literal prefix of the failure's text after "FAIL: "
#   class   defect — the arm fails on every Linux run; a row whose arm passes turns the job
#                    red, so a fix cannot land without its row being removed
#           timing — a timed arm whose result moves between runs on a shared runner; the
#                    row tolerates its failure and cannot demand it
#   reason  why the arm fails on Linux, in words
#
# Measured on GitHub's ubuntu-latest runner: Ubuntu 26.04, bash 5.3, gawk, GNU grep and sed,
# and the uutils coreutils.

# uutils printf rejects a %*s width of 1 MiB, so this arm's padding is never built.
block-egress.test.sh|AC-E007-V7c0:|defect|uutils printf rejects the 1 MiB %*s width, so the command never passes the cap the arm grades

# A 256 KiB command passes Linux's 128 KiB per-argument limit twice over: the suite hands it to jq
# as an argument, so its payload is never built, and the hook hands its input to an external printf
# as one. Either way the hook refuses the command as malformed input, exit 2, before the length gate
# runs, so the arm sees a refusal whose cause is not chars. The verdict is still a refusal.
block-destructive.test.sh|CEIL-AT-CAP-chars-far [en_US.UTF-8]:|defect|the 256 KiB command passes Linux's per-argument limit in the suite's payload builder and in the hook's input check, so it is refused as malformed input instead of by the length gate
