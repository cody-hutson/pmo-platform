## Rollback Strategy

**Unit of rollback = the single PR** (one branch → one squash-merge → one commit on `main`).

- **Pre-merge:** abandon the branch; `main` is untouched. CHEAP.
- **Post-merge revert:** `git revert <squash-merge-sha>` restores the prior `cleanup-orphan-state.sh` verbatim (single-file → clean revert). **Reversibility: CHEAP** (undo in minutes; operator-invoked tool, no downstream importers). Confidence: HIGH.
- **Self-test as rollback tripwire:** the expanded `--self-test` suite is the regression oracle — green post-merge = go; a red fixture = rollback trigger.
- **Operator-authorized:** rollback is operator-gated per RELEASE_PROTOCOL.md § Rollback protocol; Stage 9 Plan Review is the human gate before Execute.
