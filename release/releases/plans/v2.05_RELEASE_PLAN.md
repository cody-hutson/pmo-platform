## Summary

This release **codifies a cluster of agent-discipline rules** that currently live as operator-instance memory entries or as not-yet-governed conventions, moving each to its corpus home. It is a doc-only, additive governance release — no application code, no functional/behavioral runtime change.

The **keystone is #530** — the **memory↔corpus boundary contract**: a two-tier SSOT assignment, the no-shadow-SSOT invariant, a reliable encode-and-evict lifecycle, and a standing drift-detection audit. #530 is sequenced **first** because #531 and #527 (the per-batch encoders) are *consumers* of the contract — #530 makes the "evict + don't-shadow" half reliable. The remaining items are single-target corpus additions across the failure-mode standard, `CLAUDE.md.template`, `git-workflow.md`, the intake style guide, the ADR README authoring section, and the hub-spoke bridge.
