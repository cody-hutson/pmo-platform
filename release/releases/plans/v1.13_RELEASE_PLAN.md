### Deviation Log (#319 — Tier 1 [ADJUST], committed with rationale per the inter-stage feedback protocol)

The #718 spec assigned `block-egress` and `block-destructive` to Option A (materialized deployed layout). Empirical verification during Engineering — which the spec explicitly invited ("Engineering chooses the lowest-friction co-location") — found that the materialized layout is **necessary but not sufficient** for those two: each carries a **stale test fixture** the spec did not anticipate. Both are mechanical in-test corrections within the spec's Option-A contract ("the allowlist contains the boundary roots resolved for the layout under test"), of the same class as the spec's authorized Class-2b one-line format fix.
