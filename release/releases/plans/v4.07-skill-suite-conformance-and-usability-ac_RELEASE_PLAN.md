## Change Description

*Authored at Stage 6 Phase C1 per RELEASE_PROTOCOL § Change Description Protocol. Operator-facing. Refreshed on any Tier 1 [ADJUST] that changes which issues land or which D-decisions stand.*

### Outcome

Two classes of silent failure get an enforcement surface. The first: a capability can pass every acceptance criterion and all of CI while shipping **dormant** — structurally present, never actually usable — because an acceptance-criteria set that asserts only presence cannot catch a missing activation path. Capability-class work items now owe one **usability AC**: an observable behaviour the capability performs *after install*, exercised against a named fixture. The second: skills whose trigger descriptions overlap route ambiguously, and nothing watched for it. A standing gate now measures trigger collision across the whole skill suite on every deploy check, and a second standing gate catches cross-skill citations that rot the moment a file's line numbers shift.
