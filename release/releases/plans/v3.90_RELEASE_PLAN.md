## Release Outcome Statement

**AFTER:** An operator can install, update, self-diagnose, and CI-gate the PMO platform across macOS, Linux,
and Windows — and route work-tracking across multiple segregated destinations — without a WSL/Git-Bash
prerequisite, silent partial-update failures, or public/private cross-contamination.

**BEFORE:** Install/update assume a POSIX shell run from the repo root (Windows needs WSL; a non-repo-root
cwd silently half-updates in Phase 5); there is no self-diagnostic, no cross-platform CI gate, no executable
QA regression suite, and work-tracking is a single-destination scalar with no scope-segregation guardrail.

**Success Indicator:** a clean Windows fixture reaches a working operator state with no bash prerequisite (re-scoped
to the `install.ps1 -DryRun` proxy — see AC-4 Re-Scope); `./doctor.sh` + `./qa.sh` run green in the cross-platform
CI matrix; a non-repo-root `update.sh` completes Phase 5; PII-marked content is hard-blocked from a `scope: public`
destination.

## Stage-5 A6.5 Adversarial-Review Amendments (absorbed into scope; no re-quota, no fission change)

Both design-heavy slices passed A6.5 adversarial review as **SURVIVES-WITH-CONDITIONS**; the conditions are
absorbed before scope-lock.

**#384 — scope-segregation hook (verdict: SURVIVES-WITH-CONDITIONS; KEEP-WHOLE, size stays L):**
- **CD-1 — Provenance-aware routing default (fail-closed).** Split the `> default` fallback: "no `[trackers.*]` configured at all" → public single-stream (legit back-compat, unchanged); "`[trackers.*]` configured AND the active project is private/unknown-scope with unset `work_tracker`" → **fail-closed** (block filing to a public destination, or require explicit selection). +0 files (logic in the DD-6 resolver + `intake-desk` create-path).
- **CD-2 — Tiered enforcement (always-block floor).** Add an unconditional always-block tier for high-confidence, near-zero-false-positive identity needles (home-path / phone / personal-email / coworker-org) → `scope:public`; mode-gate (warn-first) only the fuzzy / destination-resolution layer. +0 files (second code path in the same new hook).
- **CD-3 — Fail-closed content-extraction on the mapped-public branch.** Empty/unparseable extraction with a known `scope:public` destination → would-block(warn)/block(enforce); keep permissive fail-open only for *unmapped* destinations. +0 files.
- **CD-4 — Extend needle surface + document coverage boundary.** Add a client/project-name needle class to the gitignored operator-populated localized-context needle file; state the coverage boundary in ADR-091 + the DD-7 taxonomy section (public-filing is guarded for operator-identity PII, and for arbitrary private-project content only to the extent the operator has declared needles). +0 tracked files.

**#303 — Windows install / orchestrator (verdict: SURVIVES-WITH-CONDITIONS):**
- **CD-1 — Pin a non-vacuous `-DryRun` executable contract.** `-DryRun` MUST (a) assert Python present + version floor, (b) resolve and print the workspace/home paths via `Path.home()`, (c) run the required-file preflight, (d) execute one **real** bash-free operation (a `compose.py regen` into a temp target with an `installed_sha` round-trip assertion), and (e) print the phase plan with an explicit "SKIPPED (bash-only, deferred to #47/#48)" marker per gated phase. Prevents DryRun gate-theater (an echo-only script that passes trivially).
- **FM-3 — Name `test_update_nonrepo_root_cwd.sh` as an explicit post-change regression gate.** #382's own T1–T4 must stay green after any later change to the deploy-skills invocation path — carry-by-preservation, not carry-by-reimplementation.
- **CD-3 (folds PT-2/FM-2) — Drop the dead `import compose` + re-anchor the HOME shim.** `orchestrate.py` never composes (composition flows `lib-composition.sh → compose.py` CLI); place the `HOME`/`Path.home()` shim at the real `.ps1` Phase-3 compose.py boundary, not in `orchestrate.py`; ensure the Windows install writes `[paths]` tokens to operator.toml so the shim is belt-and-suspenders.
- **CD-2 (operator-settled) — DEFER the `orchestrate.py` rewrite to #301.** #301 (the extender) moved to milestone #48; front-loading the bash→python→bash port in #303 adds indirection and an interim shim with no POSIX benefit. v3.90 delivers the proxy + gate relaxations + `.ps1` wrappers WITHOUT rewriting the working POSIX `orchestrate.sh`. Consequence for v3.90: **#382's bash `orchestrate.sh` fix is the release's cwd fix and stays in place** (no shim deletes/re-implements it this release).
