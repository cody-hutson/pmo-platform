## Change Description

*(Stage 6 Phase C1 — operator-facing; committed on the branch before the PR is marked ready-for-review at Stage 9.)*

**Outcome.** Implements ADR-044 (skill-output ownership is entity-keyed): adds the **Finding** entity (#19) so the findings register has a governed owner, classifies the read-time status/brief/comms renderings as **ownerless**, and ships a build-time **ownership-collision gate** (deploy.sh Check 54) that escalates a would-be second maintainer while leaving the governed many-producers/one-maintainer pattern legal. Two independent hygiene edits ride along: the roster-needle extractor converges on the single-resolution `pmo_people_roster()` accessor, and the `design-exploration.md` §7 gated process-flow is retrofitted from ASCII to Mermaid.

**Issues resolved.** #2166 (Finding entity + renderings), #2168 (ownership-collision Check 54), #2074 (roster accessor convergence), #2066 (design-exploration §7 Mermaid). All marked closed at Stage 13.

**Key decisions.** (1) `Finding.severity` enum = `{CRITICAL,HIGH,MEDIUM,LOW}` (operator Collective-Review resolution of the ADR-044 `{Critical,Major,Minor}` mismatch). (2) The collision check ships as a **sibling deploy-primitive** (ADR-068), not an extension of `run_eval_audit.py`. (3) The §6 Work Item (#18) row is added alongside Finding (pre-existing D3 gap).

**Reversibility.** MODERATE / Confidence HIGH. The Finding entity amendment is additive-revertible until a consumer hard-binds it; Check 54 is revertible-to-off (`ownership-collision.mode`); the roster-accessor swap and Mermaid retrofit are CHEAP. One squash-merge → one atomic revert.

**Downstream impact.** `entity-field-lifecycle-matrix.md` (Finding write-permission rows) and any consumer of the §6 matrix will pick up entity #19 in a later slice — flagged, not in this release's scope. No public API/contract break; `deploy.sh --check` Check 54 is warn-mode initial (non-blocking).

**Cross-references.** ADR-044 (design-of-record), ADR-068 (sibling-vs-extend), ADR-018 (Work-Item Tier-2 precedent), ADR-040 (leadership-owner amendment precedent). Stage-4 plan #3446; Stage-5 designs #3466 / #3471.
