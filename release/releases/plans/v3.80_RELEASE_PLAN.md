AFTER — Seven governance/skill documents are reconciled to the state the platform
actually shipped: the Stage-4 `domain:` class list names the shipped `process` guide;
the SIOR Decision-Owner Mapping reads the structured Stakeholder Register (`decision_owner`
/ `authority`) with the free-text `## Key People` path preserved as fallback; three

failure modes + a compression pass; artifact-lint Check-4 catches displacement in either
staging bin (`08-generated` OR `_generated`); and the two rollup skills aggregate from
the tracked (Domain-B) layer citing `source_inputs` rather than re-scanning raw transcripts.

`process` (its guide shipped); the SIOR mapping still reads only free-text `## Key People`
and its residual note says the structured authority field is not-yet-shipped (it shipped
via #206); three surfaces describe CORRECTIONS as single-tier / program-only (CLAUDE.md

no-plugin families, and §7 asserts a stale "installed" plugin roster its own Row-9 addendum
contradicts; comms-writer lacks the executive-compression treatment; artifact-lint Check-4
keys on the legacy `08-Generated/` bin alone; and the rollup skills' declared inputs do not
enforce the tracked-layer read-side contract that `tracker-schemas.md` § Aggregation
source-of-truth already assigns to them.

Success Indicator: a grep battery (CIAC-1 below) over the seven reconciliation points

the structured field, all three CORRECTIONS surfaces name the per-project tier, P5 resolves

## Rollback

Whole-release rollback = `git revert -m 1` of the single release-PR merge (CHEAP / HIGH —
all 12 source edits are additive documentation/skill reconciliations; no data migration, no
runtime schema change). Per-issue commits keep each independently revertible — a late defect
in one issue drops that issue's commit and ships the other six. The two regenerated `.skill`
packages regenerate deterministically from source via `build-skill-packages.sh`, so a package
revert is never load-bearing on its own — the source is the truth.
