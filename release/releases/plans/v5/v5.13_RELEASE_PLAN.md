- **Change 1 — the canonical block.** Inserted immediately above the top-level `jobs:` line of each workflow, with one blank line above the comment and one between `cancel-in-progress` and `jobs:`:

```yaml
# Superseded-run cancellation: on a pull request, a newer run of this
# workflow for the same pull request (a new push, or a re-run on the same
# head) cancels this one. Any other event (a push to main, a tag, a
# schedule, a dispatch) keys on its own run id, so it is never cancelled

concurrency:
```

## Change Description

### Outcome

From #8440's first commit on, a newer commit pushed to a pull request cancels the in-progress and pending runs that every pull-request-triggered workflow started for the commit it replaced, so the hosted macOS runners stop serving heads nobody will merge. A run triggered by a push to `main`, a tag, a schedule or a dispatch keys on its own run id: it is never cancelled and never waits. #9007 adds the pull-request-time gate that keeps the property true as workflows are added: the `Workflow concurrency gate` job fails a pull request whose tree carries a pull-request-triggered workflow without the block, with any other form of it, with a job-level key, or with `workflow_call` or a review event beside its pull-request trigger.

### Key decisions

- **D-ReleaseClass:** `novel`. Stage 5 owned the group design, the population and the gate's predicate and host.
- **D-C / D-Concurrency:** one branch and one pull request, written serially (P0).
- **D-Version:** bump-class minor; the provisional display moved from v5.08 to v5.09 at Engineering Commit 0, after a sibling's merge claimed v5.08 (operator re-render). The number binds at the Stage-12 claim.
- **D-SupersededRunKey (A):** `${{ github.workflow }}-${{ github.event.pull_request.number || github.run_id }}` with `cancel-in-progress: true`, at workflow level. A `github.ref` key would put every push to `main` in one group.
- **D-PopulationScope (B):** all 26 pull-request-triggered workflows, not only the 7 macOS ones, so the gate can scan the whole tree. #8440 is XL; kept as one card.
- **D-RedArmEvidence (A):** one descriptive paragraph in the selection map, no stage-text edit.
- **D-AlwaysStepTail (A):** the five `always()` steps become `${{ !cancelled() }}`, so a cancelled close-out run releases its macOS runner at once instead of after about five minutes.
- **#9007:** an advisory, enforcing job in `repo-integrity.yml` over the whole tree; textual equality on the canonical lines; a pull-request trigger beside `workflow_call` is a finding (`CALLED-WITH-PR-TRIGGER`), and so is a review event beside a pull-request trigger (`REVIEW-WITH-PR-TRIGGER`); the self-test grades the exit the gate returns and the job fails an exit 0 that prints a finding; a local RED record; a pointer decision record, ADR-241, whose number binds at the Stage-12 claim.
- **Size:** 28 effective points over the 25 ceiling, kept as one release by operator override.

### Reversibility

**CHEAP — HIGH confidence.** `git revert` of #9007's commits, then of #8440's (the gate fails on `main` without the blocks); every workflow token is read-only, so a cancelled run leaves nothing half-written, and any subset of files carrying the block is safe for `main`.

### Downstream impact

- Every pull request after the merge spends a runner only on its current head; release hubs stop cancelling superseded runs by hand.
- Stage 6 and Stage 7 cite a superseded commit's CI evidence only by a job that concluded before the next push, or by the local `test-run` record (the selection map's new paragraph).
- A sibling release that adds a pull-request-triggered workflow must carry the block. `engineering-harness-pages-published` (#8983) merged first with `process-catalog-check.yml` carrying none, so this release adds the block in its Stage-12 merge of `origin/main` (`SIBLING-WORKFLOW`, DEV-26).
- Same-head re-runs (`ready_for_review`, `edited`) now cancel an in-progress older run of the same head; the newer run reports. The follow-up candidate that would remove the redundant `ready_for_review` re-runs is held for Stage 9 / 13.
