## Release Outcome Statement

**AFTER** — Three independent structure-records integrity items ship on one branch. The analysis
workspace gains an operator-local, non-blocking staleness lint that flags past-`sunset` and
missing-frontmatter `SUMMARY.md` artifacts (the deferred §4 Enforcement automation the standard
names). Two methodology-consumer skills (`tracker-manager`, `weekly-status-rollup`) read
`delivery_approach` at invocation per the shared Methodology Awareness Protocol instead of assuming
Scrum. And the Layer-1 concurrent-write detection discipline records a concrete fingerprint for the
Cowork-side workspace-root link-rewrite signal.

**BEFORE** — The analysis workspace has no staleness detector (the standard's §4 Enforcement is a
deferred follow-up); `tracker-manager` and `weekly-status-rollup` read `delivery_approach` only via
the narrow Hybrid-Two dual-framing array edge, un-anchored to the shared read contract; and the
Layer-1-dirty detection signal in `concurrency-safeguards.md` describes the abstract condition but
carries no recognizable fingerprint for the specific Cowork link-normalization corruption class.

**Actor(s)** — Platform builders and operators who maintain the git-ignored analysis workspace, run
methodology-aware PMO tracker/roll-up skills, and reconcile a primary checkout after operations-mode
sessions.

**Success Indicator** — The lint exits 0 on a clean/divergent workspace and flags exactly a seeded
past-`sunset` artifact; `grep -c "Methodology Awareness Protocol"` on the two wired skills rises from
0 to ≥1 while the two verify-only skills stay unchanged (delivery-engine=2, ppm-agent=3); the Layer-1
detection bullet names the `](pmo-platform/…)` rewrite fingerprint.

### Slice 1 — Issue #2225: analysis-workspace staleness lint

**Change Specification:**
- **Files added:** `release/tools/check-analysis-staleness.py` (single executable, py3.9, no deps).
- **Change description:** New operator-local lint reading the frontmatter of every
  `analysis/*/SUMMARY.md`. Emits hard findings `STALE` (`now > sunset`) / `STALE-WI` (`work_item`
  CLOSED + >30d grace) / `MISSING` (any of the 5 required fields absent), plus non-gating
  `INFO`/`CONFIG`/`ARCHIVED-SKIP` advisories. Default run is a read-only TSV lint (exit 0 clean / 1
  findings / 3 input-failure); opt-in interactive `--archive` offers per-item archive-or-purge that
  never mutates without operator confirm; embedded `--self-test` (injected `state_lookup` stub, no
  network). Ratified sub-decisions: archive-in-place (status→archived), embedded self-test, no CI
  workflow.
- **Acceptance criteria (from #2225, 5 crisped ACs — Stage-8 grading surface):** AC1 past-sunset /
  work_item-close finding; AC2 missing-field finding (presence-test); AC3 operator-local +
  non-blocking + confirm-gated archive/purge; AC4 clean/divergent workspace → exit 0 no
  false-positive, one seeded past-sunset → flags exactly that one; AC5 additive (no standard edit).
- **Complexity:** Medium. **Dependencies:** None.
