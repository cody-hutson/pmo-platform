## Change Description

### Outcome

The build-philosophy charter gains its **seventh** first-class value, **Portability** — the governed core binds to an external system only through an adapter, the external system's model lives inside that adapter and never redefines a governed concept, and host mechanism never leaks into host-agnostic capability text; the design-review litmus is *"does the governed concept survive a substrate swap?"* The value lands as a value-table row, a full five-surface coverage-matrix row with honest GAP markings, an enforcer-citations bullet, and a §Systemic-finding paragraph that adds its two GAP columns to the charter's named gap backlog. It is indexed as **DP-9** in the design-principle register (index-only), giving the Operator Decision Gate and Stage-8 QA a scored conformance axis for adapter and external-binding work that previously had none. In the same pass, the register's **all nine** `governing_doc` pins are recomputed against the final file (never trusted from a projection), DP-3's drifted statement is reconciled to regain `extend-before-create`, and the **BP — governance** and **BP — process** coverage cells stop advertising a wiring gap that closed some time ago.

### Issues resolved

- **#2379** — Portability as build-philosophy value 7, DP-9 in the register (index-only), and ADR-098 recording the decision kernel plus the naming decision.
- **#2601** — the two BP-domain coverage cells flipped to skill-wired citing verified consuming specialists, and the §Systemic-finding note reconciled to zero residual.

*This is a draft PR carrying both slices; both issues are marked as closed at Stage 13, not by PR auto-close. Do not merge until Stage 12.*

### Key decisions

- **Portability is a first-class *value*, not a cross-cutting discipline.** The charter scopes disciplines to those that apply to *every* domain and surface; Portability binds only external-binding surfaces, so it fails the disciplines' own defining test.
- **The value is named `Portability`, not the ticket's coined compound.** Adopting a coined term where the corpus already names the quality would be a vocabulary fork — precisely the duplicate-source failure the value being added is meant to model.
- **The value ships paired with an existing enforcer, never naming-only** — preserving the precedent ADR's invariant, and the reason the Skills cell reads as enforced rather than GAP.
- **Every register pin is recomputed, including the ones a projection calls unchanged.** Trusting "unchanged" is the documented failure mode; the precedent release shifted two pins by one line each.
- **Matrix cell verdicts are derived, not asserted** — each of the five cells is a function of the enforcer's literal scan-glob list, so a reviewer can re-derive all five from the enforcer's configuration.

### Reversibility

**CHEAP / Confidence HIGH.** A naming-and-routing row plus an enumeration cascade plus one new ADR file; a single `git revert` of the release merge restores prior state completely. The paired enforcer is pre-existing and additive — reverting the row does not remove the detector.

### Downstream impact

The Operator Decision Gate's design-principle conformance subsection and the Stage-8 QA conformance dimension gain a ninth principle to score against, firing on adapter changes, config selector changes, and host-mechanism-in-capability-text. The path-portability axis stays routed to DP-1 by design — the two leak axes route to distinct principles, and the enforcer-citations bullet carries that boundary marker explicitly so a reviewer does not double-route a hardcoded-path finding. No skill, hook, or runtime surface changes behavior; no `.skill` package embeds either target file, so no package rebuild is triggered.
