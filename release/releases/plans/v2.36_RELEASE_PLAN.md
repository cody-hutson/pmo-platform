## Scope — the milestone bundle

Milestone `69-triage-and-bundling-signals` bundles six issues that convert Stage 1–6 triage/bundling signals from agent re-derivation and standing retro lessons into codified pipeline outputs.

**Size / band:** Raw 20 (S=2, M=4: #500 S, #283 M, #662 S, #280 M, #292 M, #225 M) · effective = round_half_up(20 × 1.15) = **23** · band 15–25 → **in-band**, G3-15 PASS.

1. **#500 — directional-not-authoritative handoff principle @ intake/triage boundary (size S).** States the principle that an approved ticket authorizes the problem/outcome, not its structural premise; downstream stages treat the ticket's structure as a proposal to confirm/overturn at Solutioning. Principle statement only — the enforcing gate is #501 (separate milestone). **First writer in the 3-way `stage-02-triage.md` contention chain.**

2. **#283 — decompose priority model (urgency vs value + dependency-count signal) @ Stage 2 (size M).** Splits priority's triple duty (urgency / importance / scope) into urgency vs value with a dependency-count triage signal. Public corpus stays methodology-neutral (no hardwired WSJF).

3. **#662 — promote Stage 2 A3.5 native-dep mirror to a tracked tool (size S).** Promotes the A3.5 native-dependency mirror from re-derived-each-run to a tracked tool (AS2) under `release/tools/`.

4. **#280 — related-issue-cluster detection threshold + tracking-mechanism selection @ Stage 3 (size M).** Documents a Stage-3 cluster-detection threshold and a tracking-mechanism selection rule over the existing epic/cluster/sub-issue primitives.

5. **#292 — Stage 3 A6 new-track rationale fires per-milestone + new gate G3-17 @ Stage 3 (size M).** Makes the A6 new-track rationale fire per-milestone behind an enforcing gate. Takes gate ID **G3-17** (G3-13 retired per ADR-012; G3-14/G3-15 shipped via closed #293/#294; G3-16 reserved for the cross-milestone gate).

6. **#225 — sub-task container threshold (sub-issues vs PR-checklist) @ Stage 6 (size M).** Defines a threshold for the Stage-6 sub-task container choice. Blocks #213 (ms `74-controlled-deployment-environment-and-modes`) on a forward edge; ships regardless.
