G2-13 (and SR-G6) ship **enforce from v3.94**; a shipped-but-unwanted gate stays bounded not by shadow-mode but by the **reflexive introducing-release exemption** (v3.94's own issues are never gated) **and** the **scoped conditional-fire predicate** (routine operator-authored tickets PASS trivially) — so enforcement touches only the elevated-rigor post-cutover subset, and a single `git revert -m 1` removes the gate entirely (revert reversibility **CHEAP**). Overall rollback: **CHEAP–MODERATE**.
