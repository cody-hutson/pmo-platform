## Change Description

### Outcome

v2.04 gives the release pipeline two close-out improvements. First, it adds a **per-release close-out-register template** that frames the release's learnings in two complementary structures — a PMBOK-7 lessons-learned section (Situation / Outcome / Lessons / Next-cycle Actions) and a compressed Kerth retrospective (Prime-Directive recitation + the three retro questions + a one-line ritual-of-closure) — both pre-seeded from the machine-synthesized learnings-triple the pipeline already produces, so the operator's marginal effort at each close is small. Second, it **splits the in-repo RELEASE_LOG ledger** into an active head (the 10 most-recent version rows) plus a per-release archive under `release/releases/logs/`, bounding the active file, adding self-describing frontmatter, folding two completeness sub-assertions into the existing Check 32, teaching the INDEX generator to read the archive as a second row source, and documenting a self-perpetuating Stage-13 archive sweep.
