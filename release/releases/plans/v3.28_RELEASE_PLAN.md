## Change Description

### Outcome

This release names the Stage-6 Engineering concurrency behavior the hub-spoke bridge already encodes (serial under D-C SINGLE topology; per-branch-parallel under D-C OPTION-A) as a first-class **parallelism posture taxonomy** (P0–P4), and adds the control plane on top: a Stage-4 `D-Concurrency Posture` decision, a per-posture `multi-chip-safety-class` safety contract, and contention-conditional Stage-6 dispatch. The default is fully-serial when the posture is undeclared, so a release that ignores the decision behaves exactly as today. A force-push prohibition (incl. `--force-with-lease`) is named-and-excluded across every non-serial posture, closing a multi-chip lease-race that a prior release's Engineering spoke hit.
