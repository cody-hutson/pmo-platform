# Reference-block headings work as documented, and cited counts stay current

2026-08-15 · v4.25

If you write a reference block under the `Source(s)` or `Related` heading, the durability checks now recognize it — those spellings failed before, even though the tooling's own error message named them as valid. Documents that restated a fact owned elsewhere — a mode list, a criterion range, a check count — now cite the source instead, so they stop going stale when that source changes.

## What changed for everyone using the platform

- **Reference-block headings.** `Source(s)` and `Related` now count as reference-block headings, alongside the spellings that already worked. *Why it matters:* a reference block written under the spelling the gate's own error message recommends is recognized instead of silently missed.

- **Release-readiness scoring covers every structural criterion.** The bundle gate's structural pass rate is computed over every criterion marked structural, rather than over a fixed list of four that a stale range named. *Why it matters:* the score can no longer read a perfect 1.0 while half the structural criteria go unmeasured — eight are live where four were counted.

- **The autonomy-tier spec no longer miscounts a skill's modes.** It cites the QA auditor's own mode list instead of claiming four numbered modes. *Why it matters:* that skill is letter-keyed and has gained two modes since the old wording was written, so the spec was telling readers something false.

- **The Stage 7 check list matches its own enumeration.** The structural-review step marks each check conditional where it is conditional, instead of stating a split its own list contradicts. *Why it matters:* the number of checks you read is the number you get.

- **A load-bearing label is documented as load-bearing.** The legacy `type:subtask` label now carries a do-not-remove entry naming the three tools that read it. *Why it matters:* deleting it as unused would have quietly shrunk two membership counts, with no error to notice.

- **Divergent copies of the reference pattern are found wherever they live.** A scan across every tracked shell, YAML, Python and awk file fails the run when a copy of the reference-block pattern has drifted from the canonical one. *Why it matters:* a copy that drifts is caught by the check itself rather than by someone eventually noticing.

## Known limits

- **Only the reference-block pattern gets the discovered-population scan.** The other six detector constants are still compared against a fixed three-file list, so a copy of one of those living outside those files would not be found.
- **`Related ADRs` is deliberately still not recognized** as a reference-block heading. The ADR authoring guide forbids a bare issue number in that section, so recognizing it would let the gates accept exactly the placement the guide prohibits. The exclusion is structural: the pattern ends immediately after the heading word, so no spelling of `Related` admits it.
- **Two byte-identical copies of other detector constants are recorded, not resolved.** They sit inside the platform check script, held to the canonical file only by an adjacent comment. No work item in this release owned that change, and the new entry says so rather than presenting them as exempt.

Report issues on the platform's GitHub issue tracker.

## Reversibility

CHEAP / HIGH. Reverting the release merge restores every file; the one added file is a test fixture nothing else depends on, and no operator data is touched. One step travels with the revert: re-run the platform deploy so the mirrored copy of the release-process rules matches the restored source.

### Operator and engineering detail

**The earlier consolidation's completeness probe was name-shaped, which is why a divergent copy survived it.** The shared detector library's header claimed sole declaration of its seven constants. That claim was verified by searching for each constant's *name*, so a copy carried under a different variable name was invisible to it by construction — the probe and the defect are negatively correlated, because a renamed copy is precisely what a name search cannot see. A value-shaped census across the 284 tracked shell, YAML, Python and awk files found three non-sourcing declaration families, all three of which a name-shaped census returns zero for. The header no longer claims sole declaration. It claims canonical declaration over an enumerated set, names each deliberate exclusion together with the different question that surface answers, and records the two byte-identical copies nobody owned as an open duplication rather than laundering them into the exemption list.

**The reference-block constant had zero behavioural coverage before this release**, and that measured gap is what the new fixture closes. The existing suite could assert the constant was *set*; nothing asserted that a copy of it still *agreed*. The new arms run over a discovered population instead of a hardcoded target list: the runner materialises each row as a one-line file, enumerates the throwaway root from the filesystem rather than from the list, and runs the real scan over it — so one row exercises discovery, the path guard, the detector and the value comparison together. The name-anchored arm is precise and fails the run; the value-shaped arm is advisory, matches on a conjunction, and is the only one that can see a copy under a different variable name.

One row per test case — the expectation, the arm, then the path and the line content that arm must classify:

```
FLAG	REFBLOCK-DECL	core/deploy/tools/divergent-plain.sh|REFBLOCK_RE='^#{1,6}[[:space:]]+([Ii]ssue [Rr]eferences|[Rr]eferences)[[:space:]]*:?[[:space:]]*$'
CLEAN	REFBLOCK-DECL	core/deploy/tools/identical-plain.sh|REFBLOCK_RE='@@CANONICAL@@'
```

**The canonical surface was the one out of conformance, not the consumer.** The reflex remediation — make the divergent copy byte-identical to the canonical value — would have regressed a documented correction. The gate's own failure message, the ADR README and the reference-durability standard all name `Source(s)` as recognized; the canonical pattern did not match it, because `[Ss]ources?` accepts `Source` and `Sources` but not the parenthetical form, whose closing bracket then met the terminating anchor and failed. The consumer already agreed with the documentation. The disposition was therefore recorded direction-first — the canonical library is the non-conformant surface — and the implementation was corrected to the stated set rather than the documentation narrowed to the implementation.

**The gate metric under-selected by exactly half.** The bundle gate's structural pass rate was defined over `G3-01 through G3-06`, with four criteria named inline. The live table carries eight rows whose check type reads structural, so a pass rate of 1.0 could be reported while four structural criteria were failing and never reached the metrics layer. The definition is now the selector rather than a snapshot of it — every Gate 3 row whose `Check` column reads `structural` — with the retired tombstone excluded by the predicate because it carries no check type at all. The same substitution was applied to the two earlier gate boundaries, which carried the same shape.

**Four cards converged independently on one durable form: delete the copy, cite the source.** The check-count card replaced a stated partition with the rule that generates it; the mode-range card replaced an enumerated mode list with a citation to the skill that owns it; the range-citation card replaced ID ranges with a property-based selector; the divergent-copy card made a non-sourcing consumer read the canonical library. A fifth instance of the same reasoning already sat in the corpus, reached independently through a different card in an earlier release — the QA Lead skill declines to restate the auditor's mode set "neither as a literal nor as a letter range", for exactly the reason the mode-range card gives.

**The durability claim is historical rather than hypothetical.** The removed text `Modes 1-4` was written on 2026-06-05. The auditor gained Mode I on 2026-07-25 and Mode J on 2026-07-30. The old form was falsified twice by real events in the ten weeks it stood, and the citation that replaced it would have required no edit on either occasion.
