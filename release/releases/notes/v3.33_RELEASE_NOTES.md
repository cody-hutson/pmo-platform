# Governance-domain specialist skills now share one best-practice anchor

2026-06-30 · v3.33

The six governance-domain specialist agents — project manager, program manager, program coordinator, portfolio manager, knowledge manager, and release planner — now ground their work in one shared governance best-practice guide instead of asserting practices ad-hoc. This is the governance-domain sequel to v3.30, which did the same for the software-domain specialists.

## What changed for everyone using the platform

- The governance-domain specialist skills now cite a shared best-practice guide (PMBOK 7th, PRINCE2, SECI, Diátaxis) as their design-time anchor. *Why it matters:* their guidance is grounded in one consistent source rather than per-invocation judgment.
- No new commands, no workflow changes, and nothing breaking — this is a consistency and governance-accuracy improvement. <!-- impact:foundational -->

## Known limits

- Two of the three domain best-practice guides are now wired to their specialist skills (software in v3.30, governance here). The **process** best-practice guide is authored but not yet wired to its specialist skills — that lands in a sibling release.

Report issues at https://github.com/cody-hutson/pmo-platform/issues.

## Reversibility

**CHEAP / HIGH confidence.** Every change is an additive reference pointer; rolling back is reverting the release PR with no data migration.
