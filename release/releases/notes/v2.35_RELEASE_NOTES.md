# Agents now calibrate their own confidence before acting

2026-06-27 · v2.35

Agents have a written way to decide, at a non-obvious decision point, whether to proceed now, pause to learn more, or escalate — based on whether independent cross-checks agree, not on how confident they say they feel, and scaled to how costly being wrong would be. The first place this runs live is the release pipeline's check that decides whether to leave a bundled release alone, amend it, re-bundle it, or defer it. Additive throughout — a new spec, a new decision record, and edits that wire the gate into existing disciplines and one pipeline stage, with no behavior or data change to anything already in place.

## What changed for everyone using the platform

- **Agents decide proceed, pause-to-learn, or escalate from a grounded signal.** Before acting on a non-obvious decision, an agent now reads a signal built from whether independent cross-checks agree, whether the missing fact can be named, and how weak the supporting evidence is — never from self-reported confidence — and picks the action by how reversible the decision is rather than by one fixed cutoff. *Why it matters:* the same uncertainty proceeds on a cheap, easily-undone action but pauses or escalates on a costly one, so you get fewer needless pauses on trivial calls and fewer confident-but-wrong commits on expensive ones.
- **A pause now has to actually learn something, and always ends.** When the gate says pause, the agent runs a short, capped loop that fetches one new piece of outside information, re-checks, and then proceeds, routes the gap to a separate investigation, or escalates — it cannot loop forever or "pause" without fetching anything. *Why it matters:* a pause becomes a real gap-close with a guaranteed exit instead of an open-ended stall dressed up as diligence.
- **The release pipeline's bundle currency-check runs the gate first.** The Stage-4 check that decides whether to leave a bundled release alone, amend it, re-bundle it, or defer it now runs this proceed-vs-pause gate before making that call. *Why it matters:* a low-confidence call on a costly re-bundle re-reads the canonical state before committing, rather than acting on weak grounds.

## Known limits

- The gate is wired into one live consumer this release (the Stage-4 bundle currency-check); adopting it at other decision points is follow-on work, not shipped here.
- The gate fires only on genuine decisions — proposing an action, a plan, a defer/do-now choice — not on observations, status summaries, or a well-understood one-line action that is already well-grounded and cheap to undo.
- The change applies to release work entering the pipeline after this release; the release that introduced it is exempt by design.

### Operator and engineering detail

**Decision-Confidence Protocol (#2286).** A new spec at `core/specs/decision-confidence-protocol.md` defines the mechanism as a compose-not-redefine layer over five existing docs. Its three load-bearing parts: (1) a **confidence signal** collapsed to three ordinal states (`CONVERGENT` / `DIVERGENT` / `UNGROUNDED`) from three observable sources — cross-check agreement, gap-namability, and the weakest evidence label — with verbalized self-confidence named and rejected as an input; (2) a **reversibility × autonomy threshold matrix** that selects PROCEED / PAUSE-TO-LEARN / ESCALATE per cell, refusing a single global numeric cutoff, with two cross-axis invariants (IRREVERSIBLE never auto-proceeds on a non-`CONVERGENT` signal; the matrix lowers ceremony but never raises an action's autonomy tier); and (3) a **bounded pause-to-learn loop** (default 1 cycle, hard cap 2) whose gap-closer imports the discovery-discipline knowability triage and whose four exit conditions guarantee termination. A six-domain application table and the named live consumer (§6) round it out. Four FM entries (self-confidence smuggling, unbounded pause, global-cutoff regression, self-elevation via the gate) carry the standard 5-field template.

**ADR-047 — compose posture (#2287).** `core/ADRs/ADR-047-decision-confidence-compose-posture.md` records the architectural decision to ship decision-confidence as an extend-and-compose layer across the decision-quality docs rather than as a standalone discipline, with a per-doc relationship table that must agree cell-for-cell with the spec's §7. The slug is disambiguated from the staleness-confidence ADR — that one's "confidence" is artifact-staleness; this one's is agent self-competence.

**Pause-to-Learn registered as the third pre-action sibling (#2288).** `core/disciplines/autonomous-execution-model.md` gains a Pause-to-Learn Pattern alongside Retry and Escalate — competence-anchored and self-closing (its default resolution is the agent closing the gap, not handing the decision to the operator), firing before an action when grounds are weak on an above-CHEAP action, and chaining to Escalate only on budget-exhaustion. The companion label→gate edit in `core/specs/reversibility-protocol.md` promotes its confidence-pairing from a label into an active self-gate that reads the reversibility tier as the cost-of-error axis. The mechanism is referenced, not restated, in both files.

**Live consumer — Stage-4 currency-check (#2289).** `release/references/pipeline/stage-04-planning.md` Phase A0 now runs the proceed-vs-pause gate before rendering the Bundle Mutability refresh outcome (no-op / amend / re-bundle / defer): it computes the signal, consults the matrix, and runs the bounded pause-to-learn loop when the matrix routes to PAUSE — re-reading the milestone description, re-walking the dependency state, or re-running the refresh-trigger scan as its one new external signal. The gate is additive to the existing A0 currency checks; it introduces no new trigger, refresh-outcome path, or escalation surface, and is cutover-gated to releases entering Stage 4 after this consumer-integration's introducing release.

**Anti-theater guard (#2290).** `core/disciplines/decision-discipline.md` adds G8, extending the existing ceremony-management posture (G1–G7) to the pause-to-learn loop: a pause is load-bearing only if it can demonstrate all three observable signals — a specific new external fetch was injected, the loop stayed within its cycle cap, and it terminated on a named exit condition. A pause that cannot demonstrate all three is a guard violation, flagged exactly as an evidence-free Decision Briefing section is. A falsification test-case pair is co-located beside the guard.

**Illustrative example (proceed vs. pause-to-learn).** Two Stage-4 currency calls, same low-confidence reading, different actions because the cost axis moves:
- *Proceed:* the currency check finds a trivially-reversible **no-op** is the candidate outcome (leave the bundle as-is). Even with a divergent signal, the matrix proceeds at the CHEAP tier — pausing on a trivially-reversible call would be the theater the guard exists to catch.
- *Pause-to-learn:* the candidate outcome is a costly **re-bundle** (rewrite the milestone, re-run earlier stages) and the signal is `DIVERGENT` — a named gap (a changed dependency state) would flip the call. The matrix routes to PAUSE: the agent fetches the one missing signal (re-walks the dependency state via `gh`), re-evaluates, and then either proceeds at the existing operator-gated tier if it grounds, or escalates with the gap and what it tried as the briefing context if the budget exhausts. Same uncertainty, opposite action — which is the whole point of refusing a single global cutoff.
