The new `release/references/standards/quota-budget-protocol.md` is the protocol/schema home; `release/references/standards/pipeline-event-log-schema.md` § 3 adds the `spoke-launch` / `quota-reservation` event type carrying `tokens_used:` (reconciled to the real `payload`-convention surface — no fictional event), with `release/tools/append-pipeline-event.sh` carrying the data-driven enum + static fallback mirror (`--self-test` PASS, 11 event types). `release/ADRs/ADR-026-spoke-launch-quota-reservation-telemetry-event.md` (+ README index row, renumbered from a Stage-5 ADR-024 draft to dodge an in-flight collision) records the decision. `novel` class, CHEAP reversibility (single `git revert -m 1` of the release PR — additive text-only protocol change over the prior "launch all N" behavior; no data migration, no consumer state to unwind; deploy no-op means nothing to re-sync post-revert). **Issues #23 + #24 stayed OPEN at merge** (PR #911 used `References #23, #24` — `closingIssuesReferences` empty — so the two issues are closed manually at Stage 13 with per-AC verification evidence; Stage 8 QA ACCEPT 11/11 on #23 sub-task #787 and 6/6 on #24 sub-task #783).
