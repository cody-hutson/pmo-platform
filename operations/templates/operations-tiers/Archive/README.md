# Archive/ — the closed-projects archive

Where a project tree goes when its lifecycle state reaches CLOSED. Read-only reference from that point on: no daily status, no tracker updates, no operational processing.

**What lands here:** the whole project folder, moved intact to `projects/Archive/<Project>/`. Governance artifacts, delivery artifacts, operational trackers, raw evidence, and reference material all travel together — the archive keeps the project readable as a unit, not as scattered survivors.

**What does not:** an ACTIVE or CLOSING project, and anything that is merely stale. Archiving is a lifecycle transition, not a tidy-up. Raw evidence in particular is **never deleted and never modified** once archived.

**Who moves it:** the project-lifecycle skill's Closure mode owns the move. Do not hand-move a project tree here — closure finalizes trackers and produces the closure summary first, and a hand-move skips both.

**Retention** is governed per record class — most classes retain for the project lifetime plus one year after CLOSED, with the safe least-destructive default applying to anything unmatched.

**Authority:** `pmo-platform/core/governance/RECORDS_POLICY.md` (retention + disposition); `pmo-platform/CLAUDE.md` § Project Lifecycle.
